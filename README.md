# GATE CHECK (PPE-Detection-System)
Real-time helmet, vest, and gloves detection with YOLO and FastAPI, with a live web dashboard and violation log.
Gatecheck checks whether people at a gate are wearing the required safety gear. A custom-trained YOLO model detects people, helmets, vests, and gloves, a The web dashboard works with a webcam, an image, or a video file, flags missing gear with smoothing to reduce false alarms, and keeps a violation log with snapshots that you can export as CSV.
